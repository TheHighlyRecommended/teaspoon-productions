# Teaspoon Productions

Website for [teaspoonproductions.com](https://teaspoonproductions.com)

Built with plain HTML, CSS, and JavaScript. Hosted on Netlify.

## Structure

```
/
├── index.html        # Main page
├── style.css         # All styles
├── script.js         # Mobile nav
├── netlify.toml      # Netlify config
└── assets/
    └── thr-card.png  # THR show card image
```

## Assets

Drop the THR neon sign image into `/assets/` and name it `thr-card.png`.

## Deployment

Connected to Netlify. Any push to `main` deploys automatically.
